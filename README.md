# SG Padel Academy · Guía de entrenamientos

Guía web editable con una propuesta completa de 24 sesiones trimestrales de entrenamiento de pádel para menores.

## Qué incluye

- Cuatro bloques claros por sesión: calentamiento, técnica, bola viva y partido.
- Diagramas de pista sencillos para entender cada propuesta de un vistazo.
- Adaptación breve por categoría y nivel, desde prebenjamín hasta juvenil.
- Edición directa de títulos, ejercicios y consignas.
- Notas del entrenador y guardado local en el navegador.
- Diseño preparado para consultar en móvil, ordenador o imprimir en A4.

## Uso

Abre `index.html` con cualquier navegador moderno. No necesita instalación ni conexión a internet.

- Pulsa **Editar** para modificar cualquier texto de la sesión.
- Los campos y las notas se guardan en el navegador al pulsar **Guardar**.
- **Imprimir** genera la ficha activa en formato A4 horizontal.

Los archivos `index.html`, `styles.css`, `app.js` y `data.js` pueden editarse directamente con cualquier editor de código.

## Publicación

El repositorio incluye un workflow de GitHub Actions que publica automáticamente la rama `main` en GitHub Pages.
